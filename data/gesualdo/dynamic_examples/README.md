# Editorial Dynamics Examples

This folder contains sample quartet reductions with generated score dynamics.
The marks are editorial: the Kunst der Fuge MIDI sources do not contain printed
dynamics or varied note velocities.

The MusicXML files include visible `p`, `mp`, `mf`, and `f` dynamics plus
short crescendo and diminuendo hairpins. The MP3 files were exported from those
MusicXML files with MuseScore 4.

Current examples:

- `gesualdo_vi_libro_madrigali_22_(c)icking-archive_quartet_editorial_dynamics`
- `gesualdo_vi_libro_madrigali_17_(c)icking-archive_quartet_editorial_dynamics`
- `gesualdo_iv_libro_madrigali_3-4_(c)icking-archive_quartet_editorial_dynamics`
